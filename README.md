# ととのう

新人社員の曖昧な悩みを分解し、「何が分からないか」と「次の一歩」を見つけるWebアプリのMVPです。

## 起動

外部ライブラリは不要です。`index.html` をブラウザで開くか、次のコマンドで起動します。

```bash
python3 -m http.server 8000
```

その後、`http://localhost:8000` を開いてください。

## 現在の仕様

- 自由入力と入力ヒント
- わかっていること、分からないこと、試したこと、足りない情報への自動整理
- 整理結果の編集
- 自分で確認・誰かに相談・保留から次の一歩を選択
- 整理結果のコピーとブラウザへの記録

AI整理と送信はMVP用のブラウザ内デモです。本番運用では、社内認証、生成AI API、Slack・Teams等の送信先をサーバー側で接続してください。
